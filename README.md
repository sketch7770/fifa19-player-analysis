FIFA 19 Sports Analytics Dashboard

Project Overview:
This project focuses on analyzing FIFA 19 player data to uncover insights related to player performance, overall ratings, wages, market value, preferred positions, and international distribution.  

The project was built using SQL for data analysis and Power BI for dashboard visualization.

Objectives:
Analyze player performance and ratings
Identify top-valued and highest-paid players
Explore country-wise player distribution
Compare player positions and attributes
Understand wage and value trends in football analytics

Tools & Technologies Used:
SQL
Power BI
Excel
Data Analytics

Data Cleaning & Preparation:
Removed duplicate records
Handled missing values
Corrected data types
Standardized column formats
Cleaned player attribute values

Dashboard KPIs:
The dashboard includes:
Total Players
Average Overall Rating
Total Market Value
Average Wage
Top Rated Players

Key Insights:
Players with higher overall ratings generally had significantly higher market values and wages.
European countries dominated the player distribution in FIFA 19.
Forward and midfield positions showed the highest average market values.
A small percentage of elite players contributed disproportionately to total market value.
Younger high-potential players showed strong future valuation opportunities.

Business / Analytical Insights:
Clubs investing in younger high-potential players may achieve better long-term value.
Wage structures are heavily influenced by player ratings and international reputation.
Market value concentration among elite players highlights financial imbalance in football markets.
